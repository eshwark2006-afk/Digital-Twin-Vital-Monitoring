# Hardware Components

This document lists the main hardware components used in the Digital Twin for Vital Parameter Monitoring project.

## 1. ESP32
- Acts as the main microcontroller.
- Reads sensor data.
- Handles Wi-Fi communication.

## 2. MAX30102
- Optical pulse oximeter sensor.
- Used to measure heart rate and estimate SpO₂.

## 3. OLED Display
- Displays the measured vital parameter readings.
- Uses I2C communication.

## 4. LED Indicator
- Provides a visual indication of system status or threshold alerts.

## Project Note
The hardware configuration and measurements are part of an academic prototype.
